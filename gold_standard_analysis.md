# Gold Standard Pipeline Analysis

The "Gold Standard" pipeline in this codebase is a deterministic, five-stage mathematical methodology used to detect, cluster, and classify electromyography (EMG) signals into clinical neurotonic events. Unlike the AI models (which use Neural Networks/GRUs), the gold standard relies strictly on digital signal processing (DSP), statistics, and established clinical rules (Romstöck criteria).

This pipeline acts as the ground truth generator for training and evaluating the AI models.

## The 5-Stage Pipeline

The pipeline is managed by `GoldStandardCache` to prevent re-computation of heavy DSP operations and is divided into the following sequential steps (found in `gold_standard_pipeline.py` and `gold_standard_model.py`):

### 1. Artifact Prep (Cautery / Artifact Blanking)
- **Goal:** Remove extreme, impossible physiological values (like those caused by surgical cautery or bumping the needle).
- **Function:** Iterates through each channel and blanks values exceeding a defined threshold (e.g., 2000 µV). This prevents large electrical artifacts from skewing downstream baseline estimates.

### 2. Energy Gate (TKEO + MAD)
- **Goal:** Filter out baseline fuzz while perfectly preserving the zero-crossings of Motor Unit Potentials (MUPs).
- **Function:** `apply_energy_gate` applies:
  - A 4th-order Butterworth bandpass (or high-pass) and a 60 Hz notch filter.
  - Calculates the Teager-Kaiser Energy Operator (TKEO: `x[n]^2 - x[n-1]*x[n+1]`). TKEO highlights signals with both high amplitude and high frequency (i.e., true MUPs).
  - Estimates the noise floor using Median Absolute Deviation (MAD) of the TKEO.
  - Creates a boolean mask (`TKEO > 3 * MAD`) and dilates it by 2ms.
  - Multiplies the original filtered signal by this dilated mask, forcing the noisy baseline to exactly 0.0 while preserving the spikes.

### 3. MUP Detection (Adaptive Guardrails)
- **Goal:** Precisely locate the timestamps of individual Motor Unit Potentials.
- **Function:** `detect_mup_timestamps`
  - Applies a rolling mean and standard deviation over the TKEO signal to create a dynamic threshold.
  - Uses `scipy.signal.find_peaks` to identify trigger indices.
  - **Morphological Guardrails (The Bouncer):** For each peak candidate, it extracts a 10ms micro-window and applies checks:
    - Rejects if Zero-Crossing Rate (ZCR) is 0 (baseline shift) or > 4 (high-frequency artifact).
    - Rejects if the waveform duration is < 2ms or > 15ms.
  - Outputs a 1D NumPy array of verified timestamps in seconds.

### 4. Train Clustering & Kinematic Features
- **Goal:** Group individual MUPs into sustained clinical events (trains).
- **Function:** `extract_train_features`
  - Iterates over timestamps. If the Inter-Spike Interval (ISI) exceeds 0.5 seconds, it closes the current cluster and begins a new one.
  - For each clustered event, it extracts key mathematical kinematics:
    - **Duration:** Time from the first to the last spike.
    - **Mean/Median Firing Rate:** Extracted from the ISI (`1/ISI`).
    - **Rhythmicity (CV):** Coefficient of Variation (`std(ISI) / mean(ISI)`).
    - **Tendency (Slope):** Linear regression of instantaneous frequencies over time.
    - **Amplitude (Vpp):** Median Peak-to-Peak voltage extracted from raw signals around each peak.

### 5. Romstöck Classification & Annotations
- **Goal:** Label the clustered events using standard IONM clinical classifications.
- **Function:** `classify_emg_event`
  - Takes the kinematic features and applies a strict decision tree:
    - **Spike:** Duration < 1.0s, 1 spike.
    - **Burst:** Duration < 1.0s, multiple spikes.
    - **A-Train (High Risk):** Duration >= 1.0s, Firing Rate >= 60 Hz, Rhythmicity (CV) <= 0.15.
    - **C-Train (Polyrhythmic):** Duration >= 1.0s, Rhythmicity (CV) > 0.45.
    - **B-Train:** Duration >= 1.0s, but does not strictly meet A or C criteria.
  - The pipeline finishes by generating UI-ready region dictionaries (`events_to_annotations`) representing the "Gold Standard" human-interpretable ground truth.

## Why is it the "Gold Standard"?
Because this method relies purely on peer-reviewed mathematical transformations (TKEO, MAD, Romstöck rules) rather than black-box pattern matching, its results are considered deterministic and clinically valid. The annotations generated by this pipeline can be serialized and exported via `annotation_store.py` to be used as exact training labels for the V2 AI model (`MOGRUEANet`).
